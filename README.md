# Bike Sharing Analysis

Tutorial-based SQL/Power BI learning work. The two yearly rental CSVs and `Bike_data.pbix` remain.
Import the CSVs into SQL Server as bike_share_yr_0 and bike_share_yr_1; `SQLQuery1.sql` now supports
verified rental totals without the missing cost table. Optional `profit_analysis.sql` requires your
own verified cost rows using `cost_schema.sql`. Costs are explicitly per ride; no prices/costs are invented.
The PBIX may require its original cost data and Desktop connection updates for refresh. That original
financial dashboard is not claimed reproducible until those inputs are supplied. This is learning work,
not a main AI project; no forecasting/AI functionality is claimed.
